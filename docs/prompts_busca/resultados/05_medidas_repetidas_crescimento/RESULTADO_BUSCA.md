# Busca 05 — crescimento e resposta com medidas repetidas

Atualização de 12/10/2026: a pedido do autor, o trabalho se concentrou nos
dois candidatos selecionados: molinésias para `Orange` e percas para `CO2`.

O [parecer completo](APROFUNDAMENTO_DOIS_CONJUNTOS.md) registra fontes,
licenças verificadas, estrutura, unidades, ausências, ajustes exploratórios,
sensibilidade do recorte e recomendação de uso. As cópias preparadas e os
resultados ficam em `aprofundamento/`. Nenhum dado foi incorporado ao pacote.

A solha foi inspecionada na triagem, mas não entrou no aprofundamento:
seu trecho adulto oferece medidas repetidas sem a sequência clara de subida
até um patamar procurada para esta substituição. O arquivo de espinhosos
não pôde ser aberto; a tentativa de download retornou HTML de verificação,
preservado com extensão `.html` para não ser confundido com uma planilha.
